## 0. MVP Core(v0.1) 기준

MVP Core는 **Windows 브라우저 기본 기능**만 포함합니다: 웹 렌더링, 탭, 주소창/검색, 뒤로/앞으로/새로고침/중지, 북마크, 방문 기록, 다운로드, 세션 복원, 기본 설정, 기본 보안/권한. 읽기 전용 AI 패널은 **선택**이며, 없어도 MVP는 출시 가능합니다. Agent/Research/Library/작업 기억/Android 정식 버전은 이후 단계입니다.

### 검색

- 주소창 하나로 URL/검색.
- 기본 후보: Google, Bing, DuckDuckGo, Naver, Daum, YouTube.
- 사용자 정의 URL 템플릿 추가/삭제.
- 주소창에서 북마크/기록/열린 탭 검색.
- 검색 제안은 기본적으로 로컬(기록/북마크)만; 외부 제안은 opt-in.
