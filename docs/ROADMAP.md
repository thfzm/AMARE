# AMARE 개발 로드맵

- 문서 상태: **제안(Proposed)** — 사용자 승인 대기
- 작성일: 2026-11-03
- 전제: 1–2명의 풀타임 엔지니어 + 파트타임 디자인/QA. 일정은 팀 규모에 따라 크게 달라집니다.
- 관련 문서: [기술 스택](TECH_STACK.md), [아키텍처](ARCHITECTURE.md), [기능 명세](FEATURES.md)

> 이 로드맵은 약속이 아니라 **의사결정 지점이 있는 계획**입니다. 각 Phase는 exit criteria를 통과해야 다음으로 진행합니다. 통과하지 못하면 범위를 줄이거나 중단합니다.

> 명칭 참고: 이 작업의 **Phase 2(Windows 브라우저 본체)**는 기존 로드맵의 Phase 1(MVP Core) 중 Windows 본체 구현에 해당합니다. 아래 기존 로드맵의 Phase 2(브라우저 완성도)는 다음 단계입니다.

## 2. Phase 1 — Windows 최소 기능 (MVP)

> 현재 스캐폴딩과 SQLite 저장소가 완료되었습니다. WebView2 실제 통합은 Phase 0.5 Windows 검증 결과 승인 후 시작합니다.

### 목표

"매일 실제 브라우징에 사용할 수 있는 최소 Windows 브라우저"를 만듭니다. **AI는 선택 기능**이며, MVP 승인 기준에 포함하지 않습니다. 자율 Agent, 멀티탭 Research, Personal Library, 작업 기억, Android 정식 버전은 이후 단계로 미룹니다.

### 필수 범위(MVP Core)

- 웹 렌더링(WebView2)
- 탭 생성/닫기/전환/복원(닫은 탭)
- 주소창(URL/검색), 검색엔진 선택/관리
- 뒤로/앞으로/새로고침/중지
- 북마크
- 방문 기록
- 다운로드
- 세션 복원
- 기본 설정(테마/검색엔진/시작 페이지)
- 기본 보안: HTTPS 경고, 인증서 오류 차단, 사이트 권한(카메라/마이크/위치/알림), WebView2 트래킹 방지
- 탭 절전/메모리 관리 v0
- 프로필 1개(내부 구조/테스트는 다중 프로필 대비)
- 크래시 복구/로컬 진단 로그
- 설치/업데이트 확인/서명 검증

### 선택 범위(MVP Optional)

- 읽기 전용 AI 패널: 현재 페이지 질문, 출처 링크, Markdown/코드/표, 스트리밍/복사
- 웹 AI 사이트를 패널에서 열기(사용자 로그인)
- API 제공자 1개 설정(선택)
- **선택 기능이 없어도 MVP는 출시 가능해야 합니다.**

### 기반

- Rust 코어 + C# WinUI 3 + WebView2
- SQLite/FTS5
- FFI(C ABI) + command/event/error
- 설치 프로그램 + Authenticode + 업데이트 매니페스트 서명
- GitHub Releases(초기에는 수동 배포 가능)

### MVP에서 제외

- Workspace/탭 그룹/탭 검색/휠 전환
- 다중 프로필/시크릿 모드(구조만 대비)
- Password manager
- 확장 프로그램
- 번역/읽기 모드/강제 다크/PIP/영상 배속
- 광고 차단 커스텀 필터(Phase 2)
- Library
- Research/작업 기억
- Agent
- Android
- DRM 4K/HDR 보장
- 동기화/클라우드

### 스파이크(Phase 1 초, 3–4주)

| ID | 내용 | 성공 기준 | 중단/변경 기준 |
|---|---|---|---|
| S0 | WebView2/WinUI 라이선스/배포 | 재배포/고지/부트스트랩/약관 확인 | 미해결 시 배포 전 중단 |
| S1 | WebView2 30탭 메모리/전환 | 16GB에서 30탭, 전환 p95 < 300ms | 20탭에서 3GB 초과 시 탭 정책/엔진 재검토 |
| S2 | WebView2 기본 API | 프로필/쿠키/캐시 삭제/다운로드/권한/방문 기록 이벤트 검증 | API 누락 시 UX/범위 조정 |
| S3 | DRM/VMP | Netflix/Disney+/YouTube/Spotify 결과 기록 | 재생 불가 시 "외부 앱" 안내, 보장 범위 축소 |
| S4 | 업데이트/서명 | Authenticode+Ed25519+체크섬+롤백 검증 | 실패 시 수동 업데이트로 축소 |
| S5 | 프로필/data 격리 | 프로필 간 쿠키/기록/설정 누출 0 | 누출 시 UDF 분리 강제 |
| S6 | FFI/비동기/오류 | 왕복 p99 < 2ms, 취소/타임아웃/에러 전달 정상 | 불안정 시 IPC/경계 재설계 |
| S7 | CDP 기초(향후 Agent) | 10개 사이트 클릭/입력/스크롤/탐색 | 50% 미만 시 Agent 범위 축소 |
| S8 | 확장 기초(향후) | uBO Lite 등 5개 로드/동작 | 전부 실패 시 확장 v1 제외 |
| S9 | 광고 차단 기초(향후) | 10만 필터, 페이지 로드 지연 < 5% | 10% 초과 시 방식 변경 |

### Exit criteria

- 2주간 내부 도그푸딩에서 데이터 손실/치명 크래시 0.
- 상위 50개 사이트 + 국내 20개 사이트 기본 탐색/로그인 성공.
- 30탭 세션 복원 성공.
- 북마크/기록/다운로드/설정/세션 데이터가 재시작 후 유지.
- 테스트 프로필 간 데이터 누출 0.
- 설치/업데이트/서명 검증 성공.
- 보안 기본값(HTTPS/권한/트래킹) 우회 없음.
- 선택 AI 패널을 포함한 경우에만 AI 동작을 검증(없어도 출시 가능).

### 예상 기간

- MVP Core: 10–14주 (스파이크 3–4주 포함)
- 선택 AI 패널: +2–3주

## 3. Phase 2 — 브라우저 완성도

### 목표

"주 브라우저"로 쓰기 위한 필수 기능과 안정성을 확보합니다.

### 범위

- Workspace, 탭 그룹, 고정 탭, 탭 검색, 탭 스크롤/휠 전환
- 다중 프로필(쿠키/세션/기록/북마크/설정 분리)
- 시크릿 모드
- 비밀번호 관리자(마스터 비밀번호/자동 잠금/자동 입력/재인증)
- 다운로드 관리자(일시정지/재개/폴더/검색)
- 사이트별 권한 관리 UI
- 검색엔진 관리(추가/삭제/기본)
- 읽기 모드
- 번역(AI/번역 API, 사용자 키)
- 강제 다크 모드(가능 범위)
- 영상 배속
- PIP(가능 범위)
- 웹사이트 사이드 패널
- 북마크/기록/Library 사이드 패널
- 세션 관리(저장/복원/닫은 탭)
- 테마/새 탭 커스터마이징
- 가져오기(북마크/기록/비밀번호 CSV)
- 자동 로컬 백업/복원 v0(암호화/보존 정책)
- 자동 업데이트 설치(Windows)
- 기본 브라우저 등록
- 다중 창/탭 이동
- 접근성/키보드 단축키/IME
- 광고/트래커 커스텀 필터(오버헤드 검증 후)
- 확장 프로그램 실험(WebView2 unpacked, 제한/권한 UI)
- 성능/메모리 튜닝

### Exit criteria

- 2주 이상 매일 사용(내부)에서 P0 버그 0.
- 30탭 + 다중 창에서 UI 응답 유지.
- 비밀번호/프로필 데이터 분리 검증.
- 업데이트 설치/롤백 성공.
- 접근성 기본 점검 통과.

### 예상 기간

10–14주.

## 4. Phase 3 — AI 기반 기능

### 목표

AI를 브라우저의 자연스러운 보조 계층으로 완성합니다. Agent는 아직 포함하지 않습니다.

### 범위

- AI 패널 완성: Markdown/코드/표/링크/이미지/PDF 첨부, 복사/재생성, 대화 검색/관리
- 일반 대화: 사용자가 선택한 공식 웹 AI 사이트(ChatGPT/Gemini/Claude) 기본
- API(선택): OpenAI-compatible, Anthropic, Gemini, Ollama, 기본 모델 1개를 대화/Agent 공유
- 현재 페이지 이해(렌더링 후 DOM, Readability, 구조 보존, 인용)
- 멀티탭 분석(관련 탭 자동 선별, 사용자 지정 우선, 사용된 탭 표시)
- Personal Library: 저장/폴더/태그/검색/미리보기/편집/삭제/AI 요약/관련 자료
- 작업 기억: 조사 페이지/출처/요약/메모/미완료, 세션 간 유지
- Research: 검색어 생성/검색/페이지 분석/비교/요약/출처
- 자연어 검색(FTS + 벡터, 하이브리드)
- AI 자동 태그/폴더/제목 제안(사용자 지정 우선)
- 컨텍스트 미리보기/리댁션/사이트별 전송 금지
- 웹 AI 보조("AI 탭에서 열기 + 프롬프트 복사")
- AI 사용량/토큰/비용 표시

### Exit criteria

- 한국어/영어 문서 추출 품질 기준 통과.
- 멀티탭 질문에서 관련 탭 선별 정확도 기준 통과.
- 인용 클릭 → 원본 이동, 스냅샷 표시.
- Library 저장/검색/요약/복구 안정성.
- 프롬프트 인젝션 코퍼스 0건 성공.
- AI 미사용 시 유휴 리소스 목표 충족.

### 예상 기간

8–12주.

## 5. Phase 4 — Agent

### 목표

사용자가 보고 있는 실제 탭을 조작하는 Agent를 안전하게 제공합니다.

### 범위

- 단일 Agent 역할 전환: 일반 대화/웹 조사/자료 정리/브라우저 조작
- Agent 도구 호출은 API 경로 사용. 웹 AI는 Agent 기능을 안정적으로 지원하지 않으므로 API 설정 안내
- 실제 가시 탭 클릭/입력/스크롤/페이지 이동/검색/탭 이동
- 실시간 화면 반영, 현재 행동/단계 표시, 즉시 중지
- 사용자 개입 감지/일시정지/재개
- 권한 스코프/capability token/승인 UI/회수
- 실행 모드: 자동/반자동(기본)/항상 승인
- 승인 큐/실행 원장
- 프롬프트 인젝션 방어(지시 계층/도구 게이팅/출력 검증)
- 비밀번호 입력 도구(원문 비노출)
- 작업 결과 자동 정리(목적/수행/핵심/출처/비교/미완료)
- 작업 기억 저장
- Agent 안전 평가/레드팀

### Exit criteria

- 20개 대표 사이트에서 일반 탐색/정보 수집 성공률 기준 충족.
- 외부 영향(전송/삭제/결제) 승인 없이 0건.
- 사용자 개입 시 100% 일시정지.
- 중지 후 부작용 0.
- 인젝션 레드팀 통과.
- 실행 원장으로 재현/감사 가능.

### 예상 기간

10–14주.

## 6. Phase 5 — Android

### 목표

Windows에서 검증된 코어/데이터/정책을 재사용하되, Android에 최적화된 UI를 구현합니다.

### 선행: 엔진 결정 게이트 (1–2주)

| 기준 | GeckoView | Android WebView | Chromium 포크 |
|---|---|---|---|
| 웹 호환성 | 검증 | 높음 | 높음 |
| 보안 격리 | 중간 | 낮음 | 높음 |
| 확장 | WebExtensions | 없음 | Chrome |

## 9. MVP 정의 (가장 먼저 만들 것)

### MVP Core = v0.1 (Windows only)

**한 문장:** "Windows 11에서 웹 렌더링/탭/주소창/검색/북마크/기록/다운로드/세션 복원/기본 설정/기본 보안이 안정적으로 동작하는 매일 쓰는 최소 브라우저."

#### 반드시 포함

1. WebView2 기반 웹 렌더링
2. 탭 생성/닫기/전환/복원
3. 주소창(URL/검색) + 검색엔진 선택/관리
4. 뒤로/앞으로/새로고침/중지
5. 북마크
6. 방문 기록
7. 다운로드
8. 세션 복원
9. 기본 설정(테마/검색엔진/시작 페이지)
10. 기본 보안: HTTPS 경고/인증서 오류/사이트 권한/트래킹 방지
11. 탭 절전/메모리 관리 v0
12. SQLite 저장/복구, 서명된 설치/업데이트 확인

#### 선택 포함(없어도 출시 가능)

- 읽기 전용 AI 패널(현재 페이지 질문/출처)
- 웹 AI 사이트 패널 열기
- API 제공자 1개 설정

#### 포함하지 않음

- Workspace/탭 그룹/탭 검색/휠 전환
- 다중 프로필/시크릿 모드
- 비밀번호 관리자/확장/번역/읽기 모드/강제 다크/PIP/영상 배속
- 광고 차단 커스텀 필터
- Library/Research/작업 기억/Agent
- Android
- DRM 4K/HDR/Chrome 확장 패리티

#### MVP 성공 기준

- 2주 내부 도그푸딩에서 데이터 손실/치명 크래시 0.
- 30탭 세션 복원 성공.
- 상위 50개 + 국내 20개 사이트 기본 탐색 성공.
- 콜드 스타트 < 2초, 탭 전환 p95 < 300ms.
- 북마크/기록/다운로드/설정/세션이 재시작 후 유지.
- 테스트 프로필 간 데이터 누출 0.
- 설치/업데이트 서명 검증 성공.
- AI 패널은 선택이며, 포함 시에만 출처 검증.
